ArgSfx Assembler technical info

ArgBug MAP file format

"SIZE" magic (4 bytes): 53 49 5A 45 (ASCII "SIZE")
Then: zero or more 4-byte entries
  [0]: 2 bytes: Value High (from [0F94] (PCADDR?))
  [2]: 1 byte: Value Low  (from [0F92] (PCADDR-2?))
  [3]: 1 byte: Type ID (from AL)
Type IDs:
MAP_SHORTA: 01 - Accumulator 8-bit
MAP_SHORTI: 02 - Index registers X/Y 8-bit
MAP_LONGA: 03 - Accumulator 16-bit
MAP_LONGI: 04 - Index registers X/Y 16-bit

"SM32" magic number (4 bytes: 53 4D 33 32)
 2 bytes, number of symbols (little-endian)
Then: repeating symbols:
  - 4 bytes: address (little-endian)
  - 1 byte: length of label
  - label (ASCII)
